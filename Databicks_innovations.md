# Key Databricks Architectural Platform Features (2024–2026)

| Topic | When Released | Why Important | Links to the Highly Rated Blogs |
| :--- | :--- | :--- | :--- |
| **Open-Sourcing Unity Catalog** | June 2024 | Databricks open-sourced Unity Catalog to create the industry's first open-source catalog for data and AI governance. It eliminates vendor lock-in with an open API compatible with Apache Iceberg and Delta Lake. | [Databricks Open Sources Unity Catalog](https://www.databricks.com/company/newsroom/press-releases/databricks-open-sources-unity-catalog-creating-industrys-only-open) |
| **Databricks Lakeflow** | June 2024 | Replaces fragmented ETL pipelines by unifying SaaS and database ingestion, declarative batch/streaming transformations, and job orchestration into a single serverless, Unity Catalog-governed solution. | [Introducing Databricks Lakeflow](https://www.databricks.com/blog/introducing-databricks-lakeflow) |
| **Databricks AI/BI** | June 2024 | Introduces a compound AI-powered business intelligence product. It offers low-code Dashboards and "Genie," a conversational interface that learns underlying data semantics without requiring traditional semantic models or data extracts. | [Introducing AI/BI: Intelligent Analytics for Real-World Data](https://www.databricks.com/blog/introducing-aibi-intelligent-analytics-real-world-data) |
| **Databricks Apps** | October 2024 | Enables developers to build and deploy internal data and AI applications natively using popular frameworks (Streamlit, Dash, Gradio, React). Apps run on managed serverless compute and inherit Unity Catalog governance. | [Introducing Databricks Apps](https://www.databricks.com/blog/introducing-databricks-apps) |
| **Git Support for SQL Queries** | February 2025 | Integrates Git support directly into the Databricks SQL editor. This enables data analysts and engineers to properly version-control their SQL code and seamlessly integrate it with enterprise CI/CD pipelines. | [What's new with Databricks SQL, February 2025](https://www.databricks.com/blog/whats-new-databricks-sql-february-2025) |
| **Lakebridge Migration Tool** | June 2025 | A free migration tool designed to automate up to 80% of legacy enterprise data warehouse migrations to Databricks SQL. It accelerates migrations by automating SQL code conversion, validation, and reconciliation. | [Introducing Lakebridge: Free, Open Data Migration to Databricks SQL](https://www.databricks.com/blog/introducing-lakebridge-free-open-data-migration-databricks-sql) |
| **Attribute-Based Access Control (ABAC)** | November 2025 | Enables scaling governance without role explosion. Admins use governed tags to define policies once at the catalog/schema level, dynamically applying row-level filters and column-level masking across all data assets at query time. | [How to scale data governance with Attribute-Based Access Control](https://www.databricks.com/blog/how-scale-data-governance-attribute-based-access-control-unity-catalog) |
| **Engine Optimizations & Zstandard Compression** | January 2026 (2025 Year-in-Review) | Delivered up to 40% faster performance across production workloads without tuning. Zstandard compression became the default for all new Unity Catalog Managed Tables, driving up to 40% storage cost savings. | [2025 in Review: Databricks SQL, faster for every workload](https://www.databricks.com/blog/2025-review-databricks-sql-faster-every-workload) |
| **Automatic Identity Management (AIM)** | June 2026 | Removes friction in identity administration by allowing organizations to automatically provision and manage users, groups, and service principals from their identity provider directly to the Databricks account level. | [What's new in Databricks Platform security and compliance](https://www.databricks.com/blog/whats-new-databricks-platform-security-and-compliance-data-ai-summit-2026) |
| **Context-Based Ingress** | June 2026 | Allows enterprise security controls to make context-dependent access decisions for specific Databricks experiences (like Genie or the account console) without unnecessarily exposing the entire platform to the network. | [What's new in Databricks Platform security and compliance](https://www.databricks.com/blog/whats-new-databricks-platform-security-and-compliance-data-ai-summit-2026) |
| **Private Network Gateway for Serverless** | June 2026 | Extends the simplicity of serverless compute to private data sources and enterprise applications through a single secure connection, removing the need to manage complex individual network peering architectures. | [What's new in Databricks Platform security and compliance](https://www.databricks.com/blog/whats-new-databricks-platform-security-and-compliance-data-ai-summit-2026) |
| **Unity AI Gateway** | August 2026 | Gives enterprises a unified way to govern AI spend, security, and access across agents, external models, and tools by providing end-to-end observability and cost controls for token-based workloads. | [Unity AI Gateway is Generally Available](https://www.databricks.com/blog/unity-ai-gateway-generally-available) |
